# Letters of Light Sunday Runbook

## Safety Boundary

- No automated external sending.
- No network access.
- No irreversible action.
- Human approval is required before publish, print distribution, email send, or in-person sharing.
- Jail/facility permission is required before jail use.
- Song/media permission and facility media rules must be checked before sharing a song.

## Sunday Flow

1. Validate the canonical letter.
2. Render local-only preview artifacts.
3. Review the email preview, print packet, jail packet, and human approval checklist.
4. Append the weekly letter record.
5. Advance state only through explicit human-approved transitions.
6. Perform any real-world sharing manually and only after the checklist is complete.
