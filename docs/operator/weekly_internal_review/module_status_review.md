# Module Status Review

Status labels in this review are constrained to `promoted`, `candidate`, `blocked`, and `unknown`. Where the module registry and `docs/operator/module_artifact_index.md` already mark a module as active and reviewed, this review maps that state to `promoted`. Where a module exists in code and tests but is not registered as an active reviewed module, this review marks it `blocked` or `unknown` rather than inferring promotion.

## Notes

- The module registry currently provides the clearest authority for reviewed module status. This review therefore does not promote any unregistered module on inference alone.
- `governed_shell` is the largest status gap between code/test maturity and registry status. It is not weak technically, but it is not yet aligned with the same module-governance path as the promoted surfaces.
- `letters_of_light_core` is not an active module in the current sense. It remains important as history and compatibility evidence, not as a target for new promotion work.
