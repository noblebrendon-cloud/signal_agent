# Image Usage Plan — v0.1.0 Article Visuals

## Purpose

This plan maps article-derived visuals to publication and social downflow use. Images remain derivative artifacts. They do not create authority and must point back to the article, GitHub release, Zenodo DOI, and archive record where appropriate.

## Visual Inventory

| Visual | Primary use | Secondary use | Boundary |
|---|---|---|---|
| Hero image | Substack article header | LinkedIn article preview | Must show local observability before action, not automation |
| Spine concept image | Follow-up post about spines | Article section image | Must show identity-aligned lanes, not fake personas or separate brands |
| Bounded publication chain image | Article section image | GitHub/Zenodo proof post | Must keep repo/release/archive as authority |
| Quote card: "Artifact first. Explanation second." | X/Threads short post | LinkedIn image post | Must remain principle-only, not product claim |
| Quote card: "Observe locally. Summarize deterministically. Act last." | LinkedIn or X/Threads | Article pull quote | Must not imply external action exists |
| Quote card: spine definition | Follow-up spine explainer | Facebook/Threads short-form | Must not imply autonomous social routing |

## Substack

Use:

- Hero image as the article header.
- Optional bounded publication chain image near the section "Why GitHub Release + Zenodo DOI Matter."

Substack footer should include:

```text
Artifact references:

GitHub release:
https://github.com/noblebrendon-cloud/signal_agent/releases/tag/v0.1.0-system-coherence-spine-observability

Zenodo DOI:
10.5281/zenodo.20176462

Concept DOI:
10.5281/zenodo.20176461
```

## LinkedIn

Use:

- Hero image for the main article share.
- Quote card "Observe locally. Summarize deterministically. Act last." for a follow-up post.

Suggested match:

- Main post: article link + GitHub release + Zenodo DOI.
- Follow-up post: local observability principle + quote card.

## X / Threads

Use:

- Quote card "Artifact first. Explanation second."
- Optional short crop of the bounded publication chain image.

Suggested match:

- Short thread explaining the wrong order vs better order.
- Keep links pointing to the Substack article, GitHub release, and Zenodo DOI.

## Facebook

Use:

- Spine concept image or quote card "Artifact first. Explanation second."

Suggested match:

- Reflective version focused on building before explaining.
- Emphasize the principle without making broader product claims.

## Follow-Up Posts

1. "What is a spine?"
   - Use spine concept image.
   - Link back to the article and release.

2. "Why local observability comes before automation"
   - Use hero image or observe-locally quote card.
   - Link back to article, GitHub release, and Zenodo DOI.

3. "Artifact first, explanation second"
   - Use quote card.
   - Link back to archive record or release.

## Crops / Derivatives Needed

- Substack header: wide horizontal crop.
- LinkedIn: horizontal or square crop.
- X/Threads: square quote card.
- Facebook: horizontal or square reflective crop.

All derivatives must preserve the same non-claim boundary:

- no external platform ingestion
- no scraping
- no API automation
- no posting automation
- no messaging automation
- no autonomous metric collection
- no external actions
- no dashboard integration
