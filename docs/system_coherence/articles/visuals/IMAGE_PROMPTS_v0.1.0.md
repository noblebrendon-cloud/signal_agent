# Image Prompts — v0.1.0 Article Visuals

All prompts are derivative of `docs/system_coherence/articles/WHY_LOCAL_OBSERVABILITY_COMES_BEFORE_AUTOMATION.md` and remain bounded to v0.1.0 claims.

Do not imply external platform ingestion, scraping, API automation, posting automation, messaging automation, autonomous metric collection, external actions, dashboard integration, or live social monitoring.

## 1. Hero Image Prompt

Create a serious conceptual systems image for an article titled "Why Local Observability Comes Before Automation." Show many faint signal threads entering from the left into a calm, local, bounded structure at the center: layered ledgers, ordered lanes, and a clear containment boundary. Inside the boundary, signals become organized records and summaries. On the far right, leave external action outside the boundary as an unactivated future path, visually present but not connected. The mood should be disciplined, thoughtful, and architectural. No platform logos, no dashboards, no robots, no social media screens, no sci-fi control room. Clean composition, restrained colors, high readability, artifact-first governance and observability themes.

## 2. Supporting Concept Prompt: Spines

Create a clean conceptual image showing one coherent source identity branching into two structured lanes labeled visually as distinct but connected paths: Reflective Spine and Governance Spine. The Reflective lane should suggest writing, music, faith, narrative, human experience, and relational continuity through abstract symbols or gentle textural cues. The Governance lane should suggest systems, architecture, release artifacts, deterministic execution, and public proofs through structured blocks, ledgers, and clean diagrams. Both lanes should remain connected to the same origin and feed back into a shared continuity layer. No fake personas, no separate brands, no platform logos, no automation imagery. Serious, calm, systems-oriented.

## 3. Supporting Concept Prompt: Bounded Publication Chain

Create a structured flow visual of an artifact-first publication chain. Show a left-to-right or circular loop with labeled stages: Repo Evidence, Local Implementation, Documentation Alignment, Checkpoint Note, Release Notes, GitHub Release, Zenodo Archive, Archive Record, Public Article, Social Downflow, Signal Capture, Spine Assignment, Retention / Relationship State, Next System Input. Emphasize that authority stays with the repository, release, and archive while public article and social posts are downstream derivatives. Use clean nodes, clear arrows, and a restrained governance/observability style. Do not depict live dashboards, external platform ingestion, automated posting, scraping, APIs, or autonomous agents.

## 4. Quote Card Prompt: Artifact First

Create a minimalist quote card with the line: "Artifact first. Explanation second." Use a serious, publication-grade design with subtle ledger, archive, or release-record motifs. The card should feel like a principle from a governed system, not a motivational poster. No platform logos, no robots, no dashboards, no hype styling. High contrast, readable typography, restrained visual language.

## 5. Quote Card Prompt: Observe Locally

Create a restrained systems quote card with the line: "Observe locally. Summarize deterministically. Act last." Show subtle local records, ordered summaries, and a clear boundary around external action. The design should communicate sequence and restraint. No external platform imagery, no scraping, no API icons, no posting or messaging visuals, no dashboard UI.

## 6. Quote Card Prompt: Spine Definition

Create a clean concept quote card with the line: "A spine is a persistent identity-aligned operational lane." Use abstract lane structure from one source identity into multiple coherent paths. Keep it serious, text-forward, and systems-oriented. Avoid branding, persona imagery, platform logos, futuristic effects, or anything implying autonomous social automation.
