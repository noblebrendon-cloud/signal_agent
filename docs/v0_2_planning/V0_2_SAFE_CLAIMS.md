# v0.2 Safe Claims

Version target:

```text
v0.2-local-authoring-surface
```

## Planning-Only Claims

Allowed after Phase 20:

- "v0.2 planning defines the next controlled local authoring surface."
- "v0.2 planning preserves the v0.1 proof-pack boundary."
- "v0.2 is not production."

## v0.1 Boundary To Preserve

Keep this intact:

```text
v0.1-local-proof-pack verifies a local proof pack for formal governance and covered Governed Authoring paths. It is not a production Governed Authoring app, not a backend-wired UI, not repo-wide governance, and not complete IBVM proof.
```

Official v0.1 proof-pack link:

```text
https://github.com/noblebrendon-cloud/signal_agent/releases/tag/v0.1-local-proof-pack
```

## Candidate Future v0.2 Claim

Only after implementation and verification:

```text
v0.2-local-authoring-surface provides a controlled local authoring surface over covered proof-pack paths.
```

This claim would still need qualifiers:

- Local.
- Non-production.
- Covered paths only.
- Explicit output paths only.
- No default production writes.

## Disallowed Claims

Do not claim:

- "v0.2 is a production app."
- "The UI is backend-wired for production."
- "All authoring is governed."
- "Repo-wide governance is complete."
- "Complete IBVM proof exists."
- "Default production canonical ledgers are enabled."
- "Generated outputs are production artifacts."
- "All state mutations are gated."

## Claim Review Checklist

Before publishing any v0.2 status:

- Does the claim say local?
- Does the claim say covered paths?
- Does the claim avoid production readiness?
- Does the claim avoid backend-wired production UI?
- Does the claim avoid repo-wide governance?
- Does the claim avoid complete IBVM?
- Does the claim match executable evidence?

## Preferred One-Line Planning Summary

```text
v0.2 planning defines a controlled local authoring surface while preserving the v0.1 local proof-pack boundary.
```
